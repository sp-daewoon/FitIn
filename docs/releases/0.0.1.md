# FitIn 0.0.1 · initial preview

Source baseline: f892c3e plus version/release metadata. This release precedes exercise append/finisher development.

Includes offline React/Expo gym coaching, a 40-minute active cap, 10-second setup, manual/automatic progression, 22 exercise guides, PPL and program previews, external video links, local records and AI maintenance harness.

Validation: 41 tests, TypeScript, harness checks and web export passed for the feature baseline. Generated anatomy and exercise prescription require qualified review. Runtime phone visual QA and native integrations are unverified. HealthKit, Watch connectivity and AirPods commands are not implemented. This is a GitHub source/web preview prerelease, not an App Store/Play Store release or production-readiness certification. Existing release gates remain blocking.

App versions are recorded separately in [versions.json](versions.json). Native 0.0.1 values are reserved development targets, not shipped binaries. Exercise append and multiple finishers are intentionally excluded from this immutable release.
